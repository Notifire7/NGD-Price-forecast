## ตั้งค่าครั้งเดียว (Cowork)

1. เอาโฟลเดอร์นี้ไปวางในเครื่อง เช่น `~/Documents/NGD-Forecast`
2. เปิด **Claude Desktop** → แท็บ **Cowork**
3. กด **Work in a project or folder** ในแถบพิมพ์ แล้วเลือกโฟลเดอร์นี้
4. เลือก **Always Allow** ได้ ถ้าแน่ใจว่าในโฟลเดอร์มีแต่ของงานนี้

Claude จะเห็นเฉพาะโฟลเดอร์ที่เลือก เข้าถึงที่อื่นในเครื่องไม่ได้
ไฟล์ `CLAUDE.md` ในโฟลเดอร์นี้เป็นคำสั่งประจำ Claude จะอ่านเองทุกครั้งที่เปิดงาน

## ตั้งค่า GitHub Pages ครั้งเดียว

```bash
cd NGD-Forecast
git init && git add . && git commit -m "first"
python3 preflight.py          # ต้องผ่านก่อนถึงจะ push
git remote add origin <URL ของ repo>
git push -u origin main
```

แล้วไปที่ repo → **Settings → Pages** → Source: `Deploy from a branch`,
Branch: `main`, Folder: **`/docs`** → Save

ได้ลิงก์ถาวรสำหรับแต่ละกลุ่ม แจกครั้งเดียวจบ เดือนหน้าลิงก์เดิมใช้ได้เลย

| กลุ่ม | ลิงก์ |
|---|---|
| NGD-FO | `https://<user>.github.io/<repo>/fo/` |
| Cogen (-8) | `https://<user>.github.io/<repo>/cogen-8/` |
| NGD-LPG | `https://<user>.github.io/<repo>/lpg/` |
| Cogen (+3) | `https://<user>.github.io/<repo>/cogen3/` |

**repo ต้องเป็น public ถ้าใช้ GitHub ฟรี** — Pages จาก private repo ต้องเสียเงิน
ข้อมูลเข้ารหัสอยู่แล้วจึงยังปลอดภัย แต่แปลว่าใครก็โหลดไฟล์ไปนั่งเดารหัสได้ไม่จำกัดเวลา
ตั้งรหัสให้ยาว 16+ ตัว

## รอบเดือน

1. เอาไฟล์ Excel จาก Marketing วางใน `input/`
2. พิมพ์ใน Cowork: **"รันรอบเดือน"**

Claude จะรัน `./monthly.sh` ให้ ซึ่งทำตามลำดับนี้

1. ดึงข้อมูล + ตรวจผังคอลัมน์
2. เทียบกับรอบก่อน แล้ว **หยุดถาม** ว่าจะ build ต่อไหม
3. build ลง `docs/` (ลิงก์เดิม) และ `out/internal_*.html` (ใช้ภายใน)
4. รัน `preflight.py` — ถ้าเจอความลับจะหยุด ไม่ push
5. **หยุดถามอีกรอบ** ว่าจะ push ไหม แล้วค่อย commit + push

ที่ต้องดูให้ดีที่สุดคือผล diff — **เดือนที่เคยแจ้งลูกค้าว่าเป็นราคาจริงแต่ตัวเลขเปลี่ยน**
จะติดป้าย `←` ไว้ให้ พวกนั้นต้องโทรบอกลูกค้า ไม่ใช่ปล่อยผ่าน

รันเองในเทอร์มินัลก็ได้:

```bash
./monthly.sh            # หยิบ .xlsx ใหม่ล่าสุดใน input/ เอง
./monthly.sh --yes      # ไม่ต้องถามยืนยัน
```

## ทำไมไม่ต้องแก้โค้ดทุกเดือน

เส้นแบ่งราคาจริง/ประมาณการ คิดเองจากวันที่ในไฟล์ (cell `NGD-FO!B1`)

| Sheet | กติกา | ไฟล์ลง 11 ส.ค. 69 |
|---|---|---|
| NGD-COGEN | จริงถึง **เดือนของไฟล์** | จริงถึง ส.ค. |
| NGD-FO, NGD-LPG | จริงถึง **เดือนก่อนหน้า** | จริงถึง ก.ค. |

เพราะ Sn ของ COGEN ใช้ Wellhead เดือน N-1 ที่ประกาศแล้ว ส่วน FO/LPG ยังต้องรอ FX

สั่งทับได้ถ้าเดือนไหนไม่ตรงกติกา:
`python3 extract.py input/ไฟล์.xlsx --actual-through 2026-08`

**สิ่งเดียวที่ต้องแตะทุกเดือนคือรหัสผ่านใน `profiles.json`**

## ห้ามให้ความลับหลุดขึ้น GitHub

`.gitignore` กัน `profiles.json` (รหัสผ่าน), `data.json` + `archive/` (ราคา plaintext),
`input/` (ไฟล์ Excel ต้นฉบับ) และ `out/` (ไฟล์ internal ที่เห็นครบทุกกลุ่ม)

แต่ `.gitignore` พังเงียบ ๆ ได้ เลยมี `preflight.py` ตรวจซ้ำ 4 ชั้นก่อน push

1. `.gitignore` กันไฟล์ลับได้จริงไหม
2. มีไฟล์ลับถูก track อยู่ไหม
3. รหัสผ่านโผล่ในไฟล์ที่จะ push ไหม (รวม README, CLAUDE.md)
4. ประวัติ git ย้อนหลังเคยมีไฟล์ลับหลุดไปแล้วหรือยัง

**ถ้ารหัสหลุดขึ้น remote ไปแล้ว การลบ commit ไม่พอ** ต้องถือว่ารหัสนั้นตาย
เปลี่ยนใน `profiles.json` แล้ว build ใหม่ทันที

## กันพลาด 3 ชั้น

**1. Marketing ย้ายคอลัมน์** — ตรวจหัวตารางทุกช่องก่อนดึง ไม่ตรงคือหยุด

```
[!] หยุด — ผังไฟล์ไม่ตรงกับที่ตั้งค่าไว้:
   • NGD-FO ช่อง F6: คาดว่าเป็น คอลัมน์ Cn (ต้องมีคำว่า 'Cn') แต่เจอ 'F Factor'
```

แก้ `GROUPS` ที่หัวไฟล์ `extract.py` แล้วรันใหม่ (อย่ามักง่ายใช้ `--no-check` ผ่าน ๆ ไป)

**2. ราคาที่เคยแจ้งว่าจริงแล้วเปลี่ยน** — `diff.py` ติดป้าย `←` อันนี้ต้องโทรบอกลูกค้า

**3. สูตรเปลี่ยน** — ถ้า Selling price ของ COGEN ไม่เท่ากับ Cn + Sn แปลว่าช่อง
"ส่วนต่าง EPP" ไม่เป็น 0 แล้ว จะเตือนให้ (ตัวเลขยังถูก เพราะดึงจากคอลัมน์ Selling price
ตรง ๆ ไม่ได้บวกเอง)

## สิทธิ์ — แก้ที่ `profiles.json`

```json
{
  "profiles": [
    { "label": "NGD-FO",           "password": "<ใส่รหัสจริง>", "view": ["ngd_fo"] },
    { "label": "Cogen ค่าท่อ (-8)", "password": "<ใส่รหัสจริง>", "view": ["cogen_m8"] },
    { "label": "NGD-LPG",          "password": "<ใส่รหัสจริง>", "view": ["ngd_lpg"] },
    { "label": "Cogen ค่าท่อ (+3)", "password": "<ใส่รหัสจริง>", "view": ["cogen_p3"] }
  ]
}
```

**รหัสกลุ่มที่ใช้ได้:** `ngd_fo` · `cogen_m8` · `ngd_lpg` · `cogen_p3`

ลูกค้าที่ซื้อหลายแบบ ใส่หลายกลุ่มใน `view` เช่น `["ngd_fo", "cogen_m8"]`
อยากแยกรหัสรายลูกค้าแทนรายกลุ่มก็เพิ่ม profile ได้ไม่จำกัด
ตอน build มันพิมพ์ตารางสรุปว่ารหัสไหนเห็นอะไร — เช็คตรงนั้นก่อนส่งทุกครั้ง

## ความปลอดภัย

- ข้อมูลแต่ละกลุ่มเข้ารหัส AES-256-GCM ด้วยกุญแจสุ่ม 256-bit คนละดอก
- รหัสผ่านแต่ละชุดถือพวงกุญแจเฉพาะกลุ่มที่มีสิทธิ์ (PBKDF2-SHA256 250,000 รอบ)
- ลูกค้าที่มีรหัส FO อย่างเดียวไม่ได้แค่ถูกซ่อนแท็บ — ไม่มีกุญแจกลุ่มอื่น แกะเองก็ถอดไม่ได้

ข้อจำกัด: ตั้งรหัสยาว 12+ ตัว · ส่งลิงก์กับรหัสคนละช่องทาง · เปลี่ยนรหัสทุกเดือน ·
ส่งออกไปแล้วดึงกลับไม่ได้ (ถ้ามี SharePoint/Google Drive การแชร์แบบระบุอีเมล
ปลอดภัยกว่าเพราะเพิกถอนสิทธิ์ย้อนหลังได้)

## โครงสร้าง

```
input/     ไฟล์ Excel จาก Marketing (อ่านอย่างเดียว)
out/       dashboard ที่ build เสร็จ ตั้งชื่อตามเดือน
archive/   data.json ของรอบก่อน ๆ — หลักฐานว่าเคยแจ้งลูกค้าเท่าไร
data.json  ข้อมูลรอบปัจจุบัน

```

| สคริปต์ | หน้าที่ |
